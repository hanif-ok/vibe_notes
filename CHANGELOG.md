# Changelog

All notable changes to Vibe Notes will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-05

### Added
- Initial release of Vibe Notes
- Create, read, update, and delete notes
- Material Design 3 UI with dark mode support
- Supabase backend integration
- Real-time sync capability
- Cross-platform support (Android, iOS, Web, Windows, macOS, Linux)
- Automatic timestamp tracking
- Pull-to-refresh on notes list
- Confirmation dialogs for destructive actions
- Empty state with helpful messages
- Error handling and retry mechanisms
- Loading indicators
- Note preview with title and content
- Full-screen note editor
- Unsaved changes warning
- Comprehensive documentation (README, SETUP, ARCHITECTURE)
- SQL schema for easy Supabase setup
- Unit tests for Note model
- Development helper scripts (dev.sh, dev.bat)
- GitHub issue templates
- Contributing guidelines
- MIT License

### Features
- Clean, modern UI with card-based layout
- Notes sorted by last modified date
- Responsive design for all screen sizes
- Keyboard-friendly note editor
- Success/error feedback via SnackBars
- Environment-based configuration

### Documentation
- Complete README with setup instructions
- Detailed SETUP guide for beginners
- Architecture documentation
- Contributing guidelines
- Code of conduct
- License file

### Developer Tools
- Development helper scripts for Unix and Windows
- Environment variable template
- GitHub issue templates
- Code formatting and analysis configuration
